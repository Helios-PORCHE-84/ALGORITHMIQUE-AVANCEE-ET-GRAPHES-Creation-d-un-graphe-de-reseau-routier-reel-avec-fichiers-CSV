# ALGORITHMIQUE-AVANC-E-ET-GRAPHES-Cr-ation-d-un-graphe-de-r-seau-routier-r-el-avec-fichiers-CSV
Ce projet consiste à créer un graphe représentant un réseau routier réel à partir de fichiers CSV contenant des noeuds (localisations géographiques) et des arcs (segments de route). Le but est de stocker ces données dans des structures appropriées et de développer des algorithmes pour les exploiter.
